# RPiKit

A modular, cross-platform Swift library for Raspberry Pi hardware peripherals, displays, graphics, and typography.

## Modules

- **`RPiHAL`**: Zero-dependency Hardware Abstraction Layer protocols (`GPIOPin`, `I2CBus`, `SPIBus`) and in-memory test mocks (`MockGPIOPin`, `MockI2CBus`, `MockSPIBus`).
- **`RPiLinux`**: Concrete Linux drivers leveraging `PeripheryKit` and Linux `spidev` ioctl. Stubs on macOS for seamless development.
- **`RPiGraphics`**: High-performance monochrome graphics engine, geometric types (`Point`, `Size`, `Rect`, `PixelColor`), frame buffers, and universal typography renderer with word-wrapping, multi-line support, and alignments (`.left`, `.center`, `.right`).
- **`RPiDisplays`**: Unified display drivers conforming to `MonochromeDisplay`:
  - `SSD1306` (128x64 I2C OLED)
  - `SSD1681` (200x200 SPI Waveshare 1.54" E-Paper)
  - `VirtualDisplay` (In-memory ASCII terminal display for local preview/unit testing)
  - `CoalescedRenderer` (Actor for coalescing rapid state updates during slow e-paper refreshes)
- **`RPiPeripherals`**: High-level hardware components such as `DebouncedButton` with `AsyncStream` event delivery.

## Fonts & `swift-font-converter` Compatibility

`RPiKit`'s font models (`BitmapFont`, `ProportionalFont`, `ProportionalGlyph`) are 100% compatible with the Swift code generated by `swift-font-converter` (`convert-font`).

Bundled presets include:
- SF Pro (`.title20`, `.titleMedium20`, `.body16`, `.bodyMedium16`, `.label11`, `.counter44`)
- SF Pro Label (`.label9`)
- SF Pro Rounded (`.roundedBold18`)
- Menlo (`.menlo12`)
- Standard 8x8, 8x16, 16x16, 24x24 bitmap fonts

## Usage

```swift
import RPiKit

// Initialize OLED (auto-uses /dev/i2c-1 on Linux, Mock on macOS)
let oled = SSD1306()
try oled.initialize()
oled.clear()
oled.drawString("Hello RPi", atX: 0, y: 0, font: .titleMedium20)
oled.drawHorizontalLine(y: 26)
oled.drawString("READY", atX: 0, y: 28, font: .label9, alignment: .right)
try oled.display()

// Monitor Hardware Button
let button = DebouncedButton(chipPath: "/dev/gpiochip0", pinNumber: 27)
for await event in button.events() {
    switch event {
    case .pressed:
        print("Button Pressed!")
    case .released:
        print("Button Released!")
    }
}
```
